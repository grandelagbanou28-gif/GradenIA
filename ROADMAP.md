## Comment contribuer

Pour contribuer a la roadmap :

1. Ouvrez une issue avec le label `roadmap`
2. Decrivez votre idee
3. Expliquez pourquoi elle serait utile
4. Proposez un plan d'implementation

## Priorites

Les priorites sont definies selon :

1. **Impact utilisateur** : Nombre d'utilisateurs concernes
2. **Faisabilite** : Complexite technique
3. **Demande** : Nombre de demandes similaires
4. **Securite** : Impact sur la securite
