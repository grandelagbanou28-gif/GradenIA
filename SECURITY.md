# Politique de Securite

## Signaler une vulnerabilite

Si vous decouvrez une vulnerabilite de securite dans Graden IA, veuillez **ne pas la rendre publique**.

Envoyez un email a : [grandelagbanou28@gmail.com](mailto:grandelagbanou28@gmail.com)

Incluez :
- Une description de la vulnerabilite
- Les etapes pour la reproduire
- L'impact potentiel
- Toute suggestion de correction

## Reponse

Nous nous engageons a repondre dans les 48 heures et a travailler avec vous pour comprendre et corriger le probleme.

## Confidentialite

Nous ne partagerons pas les details de la vulnerabilite avant qu'elle ne soit corrigee.

## Remerciements

Nous remercions tous les chercheurs en securite qui signalent de maniere responsable les vulnerabilites.
