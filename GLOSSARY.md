# Grden IA - Glossaire

## A

**API (Application Programming Interface)**
Interface de programmation permettant la communication entre differents logiciels.

**Authentification**
Processus de verification de l'identite d'un utilisateur.

**Avatar**
Image de profil representant un utilisateur.

## B

**Backend**
Partie serveur d'une application, cote serveur.

**Build**
Processus de compilation et de preparation du code pour la production.

## C

**Chat**
Conversation en temps reel avec un modele IA.

**CRUD (Create, Read, Update, Delete)**
Operations de base sur les donnees.

**CORS**
Cross-Origin Resource Sharing - mecanisme de securite pour les requetes inter-domaines.

## D

**Docker**
Plateforme de conteneurisation pour les applications.

**Dashboard**
Tableau de bord avec les informations principales.

## E

**Endpoint**
Point d'entree d'une API.

**Embedding**
Representation vectorielle d'un texte.

## F

**FastAPI**
Framework web Python haute performance.

**Fork**
Copie d'un depot Git sur son propre compte.

## G

**Git**
Systeme de controle de version distribue.

**GPU**
Graphical Processing Unit - unite de traitement graphique.

**Grden IA**
Notre assistant IA personnel.

## H

**Hugging Face**
Plateforme de partage de modeles IA.

## I

**IDE**
Integrated Development Environment - environnement de developpement integre.

**Interface**
Partie visible et interactive d'une application.

## J

**JWT (JSON Web Token)**
Format de token securise pour l'authentification.

## L

**LLM (Large Language Model)**
Modele de langage de grande taille.

## M

**Markdown**
Langage de mise en page leger.

**Middleware**
Logiciel intermediaire entre deux applications.

## N

**Node.js**
Environnement d'execution JavaScript cote serveur.

## O

**OAuth**
Protocole d'authentification securise.

**Ollama**
Plateforme pour l'execution de modeles IA locaux.

**Open WebUI**
Interface web open source pour les modeles IA.

## P

**Payload**
Donnees envoyees dans une requete API.

**Pull Request**
Demande de fusion de branches dans Git.

**Python**
Langage de programmation utilise pour le backend.

## Q

**Query**
Requete de recherche ou d'interrogation.

## R

**RAG (Retrieval-Augmented Generation)**
Technique combinant recherche et generation de texte.

**Rate Limiting**
Limitation du nombre de requetes.

**REST API**
API suivant les principes REST.

## S

**Svelte**
Framework JavaScript pour les interfaces utilisateur.

**SSE (Server-Sent Events)**
Evenements envoyes par le serveur en temps reel.

**Store**
Magasin de donnees cote client.

## T

**TailwindCSS**
Framework CSS utilitaire.

**Token**
Jeton d'authentification.

## U

**UI (User Interface)**
Interface utilisateur.

**Upload**
Envoi de fichiers vers le serveur.

## V

**Validation**
Verification de la conformite des donnees.

**Vector Store**
Magasin de vecteurs pour la recherche semantique.

## W

**WebSocket**
Protocole de communication en temps reel.

**Webhook**
Mecanisme de notification automatique.

## X

**XML**
eXtensible Markup Language - langue de balisage.

## Y

**YAML**
YAML Ain't Markup Language - format de configuration.

## Z

**Zero-shot**
Capacite d'un modele a effectuer une tache sans entrainement specifique.
