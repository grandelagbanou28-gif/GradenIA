# Grden IA - Regles de validation

## Branche main

- Pas de force push
- Reviews obligatoires
- Tests doivent passer
- Pas de secrets

## Branches de feature

- Nom : `feature/nom-fonctionnalite`
- Branche depuis `main`
- PR vers `main`
- Tests obligatoires

## Branches de bugfix

- Nom : `bugfix/nom-correction`
- Branche depuis `main`
- PR vers `main`
- Tests obligatoires

## Branches de release

- Nom : `release/version`
- Branche depuis `main`
- PR vers `main`
- Tags obligatoires

## Branches de hotfix

- Nom : `hotfix/nom-correction`
- Branche depuis `main`
- PR vers `main`
- Tests obligatoires
- Merge rapide
