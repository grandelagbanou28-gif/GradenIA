API Reference

Documentation complete de l'API Graden IA

Vue d'ensemble

L'API Graden IA suit les conventions REST et utilise JSON pour les echanges de donnees. Toutes les API sont accessibles via http://localhost:8080.

Authentication

La plupart des API necessitent un token d'authentification :

Authorization: Bearer <token>

Obtenir un token

POST /api/v1/auths/signin
Content-Type: application/json

{
  "email": "votre@email.com",
  "password": "votre-mot-de-passe"
}

Endpoints Chat

Envoyer un message

POST /api/v1/chat/completions
Content-Type: application/json
Authorization: Bearer <token>

{
  "model": "qwen2.5:0.5b",
  "messages": [
    {"role": "user", "content": "Bonjour !"}
  ],
  "stream": true
}

Reponse

{
  "id": "chatcmpl-123",
  "object": "chat.completion",
  "created": 1677652288,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Bonjour ! Comment puis-je vous aider ?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 9,
    "completion_tokens": 12,
    "total_tokens": 21
  }
}

Endpoints Modeles

Lister les modeles

GET /api/v1/models
Authorization: Bearer <token>

Reponse

{
  "data": [
    {
      "id": "qwen2.5:0.5b",
      "object": "model",
      "created": 1677652288,
      "owned_by": "ollama"
    }
  ]
}

Endpoints Ollama

Lister les modeles Ollama

GET /ollama/api/tags

Telecharger un modele

POST /ollama/api/pull
Content-Type: application/json

{
  "name": "qwen2.5:0.5b"
}

Actualiser les modeles

POST /ollama/api/refresh

Endpoints Fichiers

Upload un fichier

POST /api/v1/files/upload
Content-Type: multipart/form-data
Authorization: Bearer <token>

file: <fichier>

Scanner un dossier

POST /api/v1/graden/scan-folder
Content-Type: application/json
Authorization: Bearer <token>

{
  "folder_path": "C:\\Mon\\Projet"
}

Codes d'erreur

Code Description
400 Requete invalide
401 Non autorise (token manquant ou invalide)
403 Acces interdit
404 Ressource non trouvee
429 Trop de requetes (rate limit)
500 Erreur serveur

Exemples avec curl

Envoyer un message

curl -X POST http://localhost:8080/api/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "model": "qwen2.5:0.5b",
    "messages": [{"role": "user", "content": "Bonjour"}]
  }'

Lister les modeles

curl http://localhost:8080/api/v1/models \
  -H "Authorization: Bearer YOUR_TOKEN"

Exemples avec Python

import requests

# Configurer l'API
API_URL = "http://localhost:8080"
TOKEN = "votre-token"

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Content-Type": "application/json"
}

# Envoyer un message
response = requests.post(
    f"{API_URL}/api/v1/chat/completions",
    headers=headers,
    json={
        "model": "qwen2.5:0.5b",
        "messages": [
            {"role": "user", "content": "Bonjour !"}
        ]
    }
)

print(response.json())

Exemples avec JavaScript

// Envoyer un message
const response = await fetch('http://localhost:8080/api/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    model: 'qwen2.5:0.5b',
    messages: [
      { role: 'user', content: 'Bonjour !' }
    ]
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);
