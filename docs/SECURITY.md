# Politique de Securite - Graden IA

Notre objectif est de proteger les utilisateurs de Graden IA et leurs donnees, et de gerer les rapports de securite avec un processus clair, coherent et documente.

## Versions supportees

| Version | Supportee |
| ------- | --------- |
| main    | Oui       |
| autres  | Non       |

## Signaler une vulnerability

Si vous trouvez une vulnerability dans Graden IA, merci de la signaler de maniere responsable :

1. **Ne publiez pas** la vulnerability publiquement
2. Envoyez un email a : `grandelagbanou28@gmail.com`
3. Decrivez la vulnerability en detail (steps de reproduction, impact, correctif propose)
4. Nous nous engageons a repondre sous 48h et a corriger le probleme rapidement

## Ce qui est couvert

- Failles de securite dans le code source
- Problemes d'authentification ou d'autorisation
- Injections (SQL, XSS, etc.)
- Exposition de donnees sensibles
- Executions de code a distance

## Ce qui n'est PAS couvert

- Les problemes de configuration du cote utilisateur
- Les failles dans les dependances tierces (Ollama, etc.) - signalez-les directement aux projets concernes
- Les attaques physiques ou les attaques par denial of service

## Credits

Les chercheurs en securite qui signalent des vulnerabilities de maniere responsable seront credits dans les notes de version.
