Tout ce que vous devez savoir pour utiliser Grden IA

Introduction

Grden IA est une interface de chat IA intelligente, rapide et entierement personnalisee. Elle est basee sur Open WebUI et utilise Ollama pour les modeles locaux ou Gemini pour les modeles distants.

Note : Grden IA fonctionne sur Windows, Linux et Mac. L'application desktop est disponible pour Windows.

Demarrage rapide

Pour commencer a utiliser Grden IA :

  1. Installez Ollama
  2. Clonez le depot : git clone https://github.com/grandelagbanou28-gif/GrdenIA.git
  3. Installez les dependances : pip install -r requirements.txt
  4. Lancez l'application : python launch.py
  5. Ouvrez http://localhost:8080 dans votre navigateur

Fonctionnalites

Chat IA

Discutez avec des modeles IA locaux ou distants. L'interface est fluide et intuitive.

Multi-modeles

Utilisez plusieurs modeles en meme temps. Changez de modele en un clic.

Upload de fichiers

Envoyez des fichiers ou des dossiers pour les analyser. Le code, les documents, tout est analysable.

Conversations

Gardez un historique de toutes vos conversations. Recherchez dans les messages passes.

Mode sombre/clair

L'interface s'adapte a vos preferences. Passez du mode clair au mode sombre en un clic.

Modeles IA

Grden IA supporte tous les modeles disponibles via Ollama :

Modele Taille Description
qwen2.5:0.5b 397 MB Modele rapide pour les PC modestes
qwen2.5-coder:1.5b 986 MB Optimise pour la programmation
gemma3:1b 800 MB Modele polyvalent
llama3.1:8b 4.7 GB Haute qualite, necessite plus de RAM

Telecharger un modele

# Telecharger un modele
ollama pull qwen2.5:0.5b

# Lister les modeles installes
ollama list

Configuration

Grden IA est configure par defaut pour fonctionner immediatement. Vous pouvez personnaliser :

Variables d'environnement

# .env
WEBUI_NAME=Grden IA
OLLAMA_BASE_URL=http://localhost:11434
WEBUI_SECRET_KEY=votre-cle-secrete
DEFAULT_MODELS=qwen2.5:0.5b,qwen2.5-coder:1.5b

Gemini API

Pour utiliser Gemini :

  1. Obtenez une cle sur Google AI Studio
  2. Dans l'interface, allez dans Admin Settings → Connections
  3. Ajoutez votre cle API

Application Desktop

Grden IA peut etre lance comme une application desktop native :

# Installer pywebview
pip install pywebview

# Lancer l'application desktop
python graden_desktop.py
Attention : L'application desktop est actuellement disponible uniquement pour Windows.

Docker

Pour lancer avec Docker :

# Cloner le depot
git clone https://github.com/grandelagbanou28-gif/GrdenIA.git
cd GrdenIA

# Lancer avec Docker Compose
docker-compose up -d

# Voir les logs
docker-compose logs -f

Depannage

Ollama ne demarre pas

Verifiez qu'Ollama est en cours d'execution :

# Verifier le statut
curl http://localhost:11434/api/tags

# Demarrer Ollama
ollama serve

Port deja utilise

Changez le port dans launch.py :

uvicorn.run(app, host='0.0.0.0', port=8081)

Modeles non disponibles

Telechargez un modele :

ollama pull qwen2.5:0.5b
