Installation

Installez Graden IA en quelques minutes

Prerequis : Python 3.11+, Git, Ollama. Votre PC a 15.6 GB de RAM — suffisant pour les petits modeles.

Methodes d'installation

⚡

Installation rapide (Windows)

Double-cliquez sur install.bat pour installer automatiquement.

# Le script fait tout pour vous :
# - Clone le depot
# - Installe Python + dependances
# - Installe Ollama + modeles
# - Installe les modeles IA recommandes
install.bat
🔧

Installation manuelle

Pour plus de controle sur chaque etape.

# 1. Cloner le depot
git clone https://github.com/grandelagbanou28-gif/GrdenIA.git
cd GrdenIA

# 2. Creer un environnement virtuel
python -m venv venv
venv\Scripts\activate

# 3. Installer les dependances
pip install -r requirements.txt

# 4. Lancer l'application
python launch.py
🐳

Avec Docker

Pour les utilisateurs avances qui preferent Docker.

# Cloner le depot
git clone https://github.com/grandelagbanou28-gif/GrdenIA.git
cd GrdenIA

# Lancer avec Docker Compose
docker-compose up -d

# Voir les logs
docker-compose logs -f

Installer Ollama

Ollama est necessaire pour utiliser les modeles IA locaux.

Windows

# Telecharger depuis le site officiel
# https://ollama.com/download/windows

# Ou avec winget
winget install Ollama.Ollama

Linux

# Installer Ollama
curl -fsSL https://ollama.com/install.sh | sh

Mac

# Installer avec Homebrew
brew install ollama

Installer les modeles IA

Voici les modeles recommandes pour votre configuration :

Petits modeles (recommandes)

# Qwen 2.5 0.5B — Le plus rapide (397 MB)
ollama pull qwen2.5:0.5b

# Qwen 2.5 Coder 1.5B — Programmation (986 MB)
ollama pull qwen2.5-coder:1.5b

# Gemma 3 1B — Usage general (800 MB)
ollama pull gemma3:1b

Grands modeles (plus lents sans GPU)

# MiniCPM V4.6 — Multimodal (1.6 GB)
ollama pull minicpm-v4.6:latest

# Granite Guardian 8B — Securite (4.7 GB)
ollama pull granite4.1-guardian:8b
Attention : Sans GPU, les grands modeles (8B+) sont lents. Utilisez les petits modeles pour debuter.

Configuration

Variables d'environnement

Creez un fichier .env a la racine du projet :

# .env
WEBUI_NAME=Graden IA
OLLAMA_BASE_URL=http://localhost:11434
WEBUI_SECRET_KEY=your-secret-key-here
DEFAULT_MODELS=qwen2.5:0.5b,qwen2.5-coder:1.5b,gemma3:1b

Gemini API (optionnel)

Pour utiliser Gemini au lieu des modeles locaux :

  1. Obtenez une cle API sur Google AI Studio
  2. Dans l'interface, allez dans Admin Settings → Connections
  3. Ajoutez votre cle Gemini API

Application Desktop

Pour lancer Graden IA comme une application Windows native :

# Installer pywebview
pip install pywebview

# Lancer l'application desktop
python graden_desktop.py

Lancer l'application

# Demarrer Ollama (si pas deja en cours)
ollama serve

# Lancer Graden IA
python launch.py

# Ouvrir dans le navigateur
# http://localhost:8080
C'est parti ! Ouvrez http://localhost:8080 dans votre navigateur et commencez a discuter avec l'IA.

Depannage

Erreur "Ollama not running"

# Demarrer Ollama dans un autre terminal
ollama serve

Erreur "Port 8080 deja utilise"

# Changer le port dans launch.py
uvicorn.run(app, host='0.0.0.0', port=8081)

Erreur de memoire

# Utiliser un modele plus petit
ollama pull qwen2.5:0.5b
