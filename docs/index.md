# Graden IA - Documentation

## Bienvenue

Graden IA est une interface de chat IA intelligente, personnalisee et entierement locale.

## Links

- [GitHub](https://github.com/grandelagbanou28-gif/GradenIA)
- [Documentation](https://grandelagbanou28-gif.github.io/GradenIA/)
- [Issues](https://github.com/grandelagbanou28-gif/GradenIA/issues)

## Fonctionnalites principales

- Chat IA avec modeles locaux (Ollama)
- Support Gemini API
- Upload de dossiers
- Application desktop Windows
- Interface francaise
